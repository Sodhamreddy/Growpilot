# Our Brand SEO Studio POC

A responsive, dependency-free dashboard based on the supplied SEO content automation document.

Run `node server.cjs` and visit http://127.0.0.1:4173, or open dist/index.html directly.

Includes overview, content pipeline, draft review and approval, demo scheduling, brand voice controls, keyword filtering, an explainable weighted SEO score, local review previews, channel-specific social previews, analytics, integrations, and preferences.

All metrics, sources, scores, and generated text are illustrative. No live AI, crawling, authentication, or external publishing is implemented. Brand voice and content changes persist in browser localStorage. The original document is not included in the deployed source.
